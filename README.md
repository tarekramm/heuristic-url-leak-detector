# Silent Spill – Heuristic URL Leak Detection System

Silent Spill is a heuristic-based URL leak detection system developed as part of my Master’s research work.

Designed and implemented as part of my Master’s research, later adopted by Madiba Research Lab at Concordia University.

## Official Repository

** https://github.com/Madiba-Research/silent-spill-heuristic-system**

## Project Overview

Silent Spill focuses on detecting potential URL-based information leaks using heuristic scanning techniques.
